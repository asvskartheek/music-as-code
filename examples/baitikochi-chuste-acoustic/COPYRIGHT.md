# Copyright and licensing

Not legal advice. This is a checklist to take to the rights holders before the
karaoke video is shared or published anywhere.

## The song

| | |
|---|---|
| Title | Baitikochi Chuste |
| Film | *Agnyaathavaasi* (2018) |
| Music | Anirudh Ravichander |
| Lyrics | credited online to Shree Mani (confirm on the album credits) |
| Label | Aditya Music (confirm; they publish the official video) |

## What is in this repository

| Item | Whose it is | In the repo |
|---|---|---|
| Synth, picking pattern, video code | this project | yes |
| Chord loop (F#m, C#m, Bm) and its timing | part of the song's composition | yes, as chord names |
| Original sound recording | the label | no, none is used |
| Lyrics | the lyricist / publisher | **no** |
| Rendered `.wav` / `.mp4` | derived from the composition | no, git-ignored |

## Licences to request

| Need | Why | Who to ask |
|---|---|---|
| Synchronisation licence | the composition is set to video | the publisher, usually the label for film music |
| Lyric display / reproduction | the words appear on screen | same publisher |
| Mechanical licence | a new recording of the composition | same publisher |
| Public performance | only for venues, streams or broadcasts | IPRS (India) |
| Master-use licence | not needed while no original audio is used | - |

## Status

- [ ] Lyricist and publisher confirmed from the album credits
- [ ] Written request sent (territory, platforms, duration, free or monetised)
- [ ] Sync + lyric licence received
- [ ] Mechanical licence received
- [ ] `karaoke/lyrics.lrc` added locally from the licensed text
- [ ] Credit line agreed with the rights holder and added to the video

Until the first four boxes are ticked, keep `lyrics.lrc` and every render
local, and out of this repository.
